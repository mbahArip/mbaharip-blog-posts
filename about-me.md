For the **Mini Project**, I made a markdown notes app called [Notokake](https://github.com/mbaharip/mini-project-notokake).

The project are built using React, Redux, and GraphQL.

For the **Final Project**, all the participant were grouped into a team of 8-10 people to create a complete website based on real life problem.  
Me and my team were given a task to create a website where people can check, search, and rent an office space.  
The scope of the project includes:
- User authentication
- User can search or filter a place to rent
- User can see the detail of the place
- User can chat with the owner of the place to rent
- Dashboard for super admin and owner of the place to rent
- Admin can do everything on the dashboard
- Owner can do CRUD for their place to rent, and chat with the user

<- ITEM:START title="Internship at Legal Documentation and Information Network of Bandung City" subtitle="Oct 2022 - Mar 2023" key="Internship" ->  
This internship was a cooperation program between Government of Bandung City and Sekolah Tinggi Teknologi Bandung.  
At first, me and my team observing the current system while discussing with the one who manage the system.  
Then we found a problem where the management can't handle all the question sent by the user (citizens of Bandung City).  
After discussing it more, it decided that me and my team can try to build a chatbot to help the user with basic information and find legal documents they needed.

The project were made using Next.js + Typescript, and we also use *nlp.js* for the chatbot.  
Chatbot data were gathered from the question data from the user itself.

By the end of the internship, we were able to make a fully functional chatbot that can help with basic information and also find legal document based on document type or keywords.  
We also take [some photos (via Instagram)](https://www.instagram.com/p/CpWJ0p5v7qX) at the end of internship
