# Mbaharip's Portfolio Vault

This repository contains obsidian vault for [my portfolio site](https://www.mbaharip.com).

## Structure

- `attachments`: contains all the images (or other media) used in the posts.
- `posts`: contains all the posts in markdown format. It's separated by 2 categories: `articles` and `projects`.
- `scripts`: contains all the scripts used to generate JSON files for the posts information.
- `templates`: contains templater files for the vault.
